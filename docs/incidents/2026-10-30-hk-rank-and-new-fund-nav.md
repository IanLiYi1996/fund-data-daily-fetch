## 根因与代码修复

### fund_hk_rank

AkShare 按 JSON 字段的出现位置重命名整帧。上游返回字段顺序变化后，
`CURRENCY` 被解释为基金代码，`FCODE` 被解释为基金简称，`Y` 被解释为币种。
混合数值和空字符串使 raw Parquet 序列化失败；独立执行的 Iceberg 写入却继续，
按错误的币种主键把 191 只基金折叠成四行。

`lambda/shared/fetchers/fund_fetcher.py` 改为直接读取同一上游接口，按明确的 JSON
字段名映射。数值空值统一转换为缺失值；写入前拒绝非六位数字基金代码、重复
代码和缺失必需字段。请求有超时并检查 HTTP 状态，未知新增字段不影响解析。

### 029238 的首个历史净值

`029238`（华西长盈63个月封闭债券）在湖中已有 10-29 净值 `1.0001`，
但上游还持有 10-28 净值 `1.0000`。补采原先只选择目标日没有可用净值的基金，
仅海外基金例外回看历史。该国内基金一旦被目标日快照覆盖，10-28 就不再被请求。

`lambda/fund-fallback-fetcher/handler.py` 增加近期首次出现/恢复披露基金的短期
历史探测，复用现有十天扫描，不额外扫描湖表。本次实测候选 69 个；不扩大为
全市场历史缺口回刷。写入仍只接受上游实际日期，并排除已有可用净值的日期。
